# Task 3 — NexaBank Digital ATM Portal

A web-enabled ATM banking application built with Core Java (`HttpServer`) and HTML/CSS/JS, containerized with Docker and deployed on Render.

## Live Demo
- **URL:** https://oibsip-wekr.onrender.com/
- **Account 1:** User ID `1001` | PIN `1234`
- **Account 2:** User ID `1002` | PIN `5678`

## Features
- PIN-based authentication and multi-user session handling
- Real-time deposit, withdrawal, and inter-account fund transfers
- ₹5,00,000 single-transaction limit and ₹50,00,000 maximum account balance cap
- Timestamped transaction history and persistent Light/Dark mode
